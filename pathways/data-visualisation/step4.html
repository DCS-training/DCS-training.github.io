Analyse and Modify Data with SQL

Once you've created a database and populated it with your data, you can easily manipulate the data, producing extractions and aggregations for visualisation and further analysis with Python and R.

This data manipulation is done via queries that use the SQL language.

What is SQL?

What is a query?

Requests for information from databases are done via queries. These queries are written in a language understandable by the database, usually SQL. It is always a good idea to start building your query by clearly setting out what you are trying to do and, after that, translating it into a language understandable by the computer

Through the queries, you can perform a series of tasks within your database. The main actions you can take on your data are:

  • Select
  • Order
  • Alter
  • Aggregate
  • Join
  • Extract
How to Build SQL Queries

Extracting views

An important task that you can perform via queries is creating 'views' of your data.

Views are virtual tables, containing subsets and aggregations of your dataset. Depending on the research question you want to answer, you may need to extract different views on which to perform further analysis.

Views can be saved and exported to be used in different software (e.g. Python and R). This is particularly useful if you have a very big database that might slow down analysis in R and Python: working on views rather than on the whole dataset will reduce the processing times.
